# Open Bandit Dataset sample

The first 3,000 rows of the public sample of the Open Bandit Dataset, from
https://github.com/st-tech/zr-obp/tree/master/obd (`random/all/all.csv` and `bts/all/all.csv`).
Used only by the tests. The full dataset is at https://research.zozo.com/data.html.
